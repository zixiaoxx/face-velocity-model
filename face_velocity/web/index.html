How this demo runs, evaluation scope and reproduction

Browser → FastAPI → SCRFD / five-point alignment / CASIA R50 → dynamic identity decision ↔ PostgreSQL.

Sequential replay uses cached evaluated embeddings. The API recomputes each gallery search and stores events and references in PostgreSQL. Upload mode runs extraction live.

The gallery shows only events available at the inspected point. Replay measurements summarize all processed queries. Ground-truth labels enter evaluation only after matching; one historical error can affect multiple later queries.

Docker Compose starts the application and database. See the repository README for model/data acquisition, experiments and demo setup. Pretrained weights have non-commercial research restrictions; photos and model files are acquired separately.
